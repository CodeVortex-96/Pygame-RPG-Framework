# Ordem-Engine-Core

Este repositório contém o núcleo (engine) de um projeto de RPG 2D desenvolvido em Python utilizando a biblioteca Pygame. 

### 🚀 O que foi desenvolvido:
- **Sistema de Câmera:** Implementação de câmera que segue o jogador com suporte a deslocamento (offset) de sprites.
- **Movimentação e Colisão:** Lógica de movimento baseada em vetores e detecção de colisão eficiente com obstáculos.
- **Arquitetura Orientada a Objetos:** Separação clara entre classes de Player, Tiles e o gerenciamento da lógica principal (`Level`).
- **Portabilidade:** Configuração automática de diretórios de trabalho (OS Path fix) para rodar em qualquer máquina.

### 🎨 Sobre a Arte:
O projeto foca exclusivamente na **Engenharia de Software** e na lógica de funcionamento. Os assets visuais são placeholders, focando na performance e na precisão dos sistemas de jogo.
